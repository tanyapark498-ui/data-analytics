# Banking Customer Churn Analytics

Анализ оттока клиентов банка: аудит данных, проверка гипотез, модель прогнозирования.

## Бизнес-вопрос

Какие клиенты уходят, какие факторы на это влияют сильнее всего, можно ли заранее выявить группу риска.

## Данные

`bank_churn_dataset.csv` — 80 000 клиентов, 26 признаков: демография, финансовые показатели, поведенческие метрики, сегментация. Целевая переменная — `exit` (ушёл / остался).

## Что сделано

1. **Data Audit** — пропуски, дубликаты, выбросы, диапазоны, согласованность полей
2. **EDA** — разбивка оттока по сегментам, каналам, возрасту; heatmap пересечений
3. **Статтесты** — chi-square, Mann-Whitney U, z-test с доверительными интервалами
4. **Модель** — Logistic Regression + Random Forest, ROC-AUC, feature importance, скоринг топ-20% риска

## Ключевые находки

**Сегмент — главный фактор.** Mass 39.5% против Emerging 17.6%, Affluent 3.1%, Priority 0.07%. Mass — 27% базы, но даёт 59% всех уходов.

**Цифровой канал — сильный отдельный эффект.** Без мобильного приложения уходят в 3.25 раза чаще: 21.1% против 6.5%.

**Пересечение факторов.** Mass + 18–24 года — 51% отток. Mass + offline — 46%, Mass + mobile — 16.3%.

**Engagement как предиктор.** Медиана у ушедших 16, у оставшихся 25. Разница подтверждена тестом Манна-Уитни (p ≈ 0).

**Корреляции.** Главный числовой предиктор — `risk_score` (r = 0.43). Возраст и стаж почти не влияют (|r| < 0.07).

**Модель.** Logistic Regression: ROC-AUC 0.857. Random Forest: ROC-AUC 0.855, recall по классу «Ушёл» 0.84. Обе модели работают на одном уровне — линейной границы после one-hot кодирования достаточно, нелинейные взаимодействия в данных слабые.

**Скоринг.** Топ-20% клиентов по предсказанному риску дают реальный churn 50.4% — в 2.8 раза выше среднего по выборке.

## Рекомендации

- Retention-кампании — в первую очередь на Mass, особенно 18–24 года
- Стимулировать переход в мобильное приложение у офлайн-клиентов Mass и Emerging
- Мониторить `engagement_score`: падение ниже 20 — ранний сигнал риска
- Использовать модель для скоринга: топ-20% по churn probability — приоритетная группа
